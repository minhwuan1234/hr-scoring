/Responsive.Breakpoints/ *Use the existing Toolhub CSS breakpoints at viewport widths 1100px, 760px, and 480px where the corresponding component defines them.*
/Responsive.Shell/ *At 1100px or below, sidebar width changes from 232px to 190px; at 760px or below, workspace shell becomes one column.*
/Responsive.Topbar/ *At 760px or below, top bar is 48px high with 20px horizontal padding; at 480px or below, horizontal padding is 12px.*
/Responsive.Graph/ *At 760px or below, graph canvas minimum height is 320px and the 280px tools sidebar moves below it at full width.*
/Responsive.Dialog/ *At 760px or below, Agent and Context Builder dialogs use viewport width minus 24px and height min(80svh, viewport height minus 24px).*
/Accessibility.Focus/ *Global button focus uses a 2px black outline with 3px offset; interactive graph nodes, ports, and dialog controls have visible focus styles.*
/Accessibility.Motion/ *When prefers-reduced-motion is reduce, graph connection animation, node-port transition, and chat pulse animation are disabled.*
/Accessibility.Status/ *Visible status words accompany colored graph dots; do not encode Active or Inactive through color alone.*
/Responsive.Width/ *Keep the screen usable without horizontal page overflow on narrow viewports.*
/Responsive.Order/ *Reflow multiple columns into a clear reading order on narrow screens, preserving the primary task and actions.*
/Responsive.Controls/ *Keep navigation, forms, menus, and primary actions reachable on narrow screens.*
/Accessibility.Keyboard/ *Make every interactive element keyboard reachable and show visible focus.*
/Accessibility.Semantics/ *Use semantic headings, labels, buttons, links, and status descriptions in the design.*
/Accessibility.Contrast/ *Keep text and controls legible against their surfaces and do not communicate meaning by color alone.*
/Accessibility.Touch/ *Existing primary icon targets include the 44px canvas control and 43px chat send button; keep compact controls keyboard reachable.*
