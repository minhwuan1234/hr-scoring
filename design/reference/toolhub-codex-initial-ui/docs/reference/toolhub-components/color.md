/Color.Canvas/ *Use white for the main application canvas and graph surfaces.*
/Color.Surface/ *Use restrained white and near-white surfaces with subtle gray borders and shadows.*
/Color.Text/ *Use dark neutral text for primary content and muted gray for secondary information.*
/Color.Status/ *Use green for active or ready states, amber for near-limit warnings, red for errors or exhausted limits, and gray for inactive states. Pair status colors with text or icons.*
/Color.Accent/ *Keep the palette neutral and restrained. Do not introduce a bright accent unless an existing product control or an explicit request calls for it.*
