/AgentHandoff.Default/ *New Agent Handoff nodes start in Receive data mode.*
/AgentHandoff.Dialog/ *Use the shared node dialog size, header, padding, fields, and scrolling rules.*
/AgentHandoff.Configure/ *Double-click the node or choose Configure handoff to select Receive data or Send handoff.*
/AgentHandoff.Routes/ *Show connected sources or destinations from the directed agent links on the main Toolhub canvas. Preview the latest available output.*
/AgentHandoff.Receive/ *Receive data reads the latest output from connected incoming agents.*
/AgentHandoff.Send/ *Send handoff saves the latest UI/UX output for connected outgoing agents in a browser-local handoff mailbox.*
/AgentHandoff.Sync/ *Changing or removing a main Toolhub connection updates routes and the mailbox.*
/AgentHandoff.NoImplicitRun/ *Neither handoff mode automatically calls a model or starts the destination agent.*
/AgentHandoff.ChatSync/ *When an agent is later run through Toolhub chat, include the latest data only for that routed agent: incoming output for UI/UX when an active Receive node exists, and a UI/UX delivery for each connected destination when an active Send node exists.*
/AgentHandoff.Storage/ *Main canvas links, latest output snapshots, and handoff records are stored in this browser. Cross-device or server persistence is not provided.*
/AgentHandoff.TestBrief/ *Receive mode may show an editable sample BA handoff document for one screen. Use it only as test input when enabled and no live incoming output exists. Live agent output takes priority. Editing the document does not call a model.*
